# Scroll Chat — نسخه اول

پیام‌رسان وب با ثبت‌نام، ورود، جست‌وجوی کاربران و چت خصوصی زنده.

## اجرا روی کامپیوتر
1. Node.js نسخه 20 یا جدیدتر نصب باشد.
2. در پوشه پروژه اجرا کنید:
   `npm install`
3. یک کلید امن برای JWT تنظیم کنید:
   - Linux/macOS: `JWT_SECRET="یک-کلید-تصادفی-طولانی" npm start`
   - Windows PowerShell: `$env:JWT_SECRET="یک-کلید-تصادفی-طولانی"; npm start`
4. مرورگر را روی `http://localhost:3000` باز کنید.

## انتشار روی Render
- یک Web Service جدید بسازید و فایل‌های این پروژه را در GitHub قرار دهید.
- Build Command: `npm install`
- Start Command: `npm start`
- Environment Variables:
  - `JWT_SECRET`: یک مقدار تصادفی طولانی و محرمانه
  - `DB_PATH`: `/var/data/scroll-chat.db`
- یک Persistent Disk با Mount Path برابر `/var/data` اضافه کنید تا دیتابیس بعد از راه‌اندازی مجدد باقی بماند.

## نکات
- رمز عبور کاربران با bcrypt هش می‌شود.
- توکن ورود با JWT نگهداری می‌شود.
- پیام‌ها در SQLite ذخیره می‌شوند و از طریق Socket.IO زنده ارسال می‌شوند.
- این نسخه MVP است؛ پیش از استفاده عمومی باید HTTPS، محدودسازی تعداد درخواست‌ها، سیاست حریم خصوصی، گزارش/مسدودسازی کاربران، پشتیبان‌گیری و کنترل‌های ضدسوءاستفاده اضافه شوند.
- مقدار پیش‌فرض JWT_SECRET فقط برای اجرای محلی است؛ در انتشار حتماً مقدار محرمانه خودتان را تنظیم کنید.
